## Selected work

- **[IMBONIX](https://imbonix-nisr-hackathon-2026.vercel.app/)** ([source](https://github.com/dieumerci-niyonkuru/imbonix-nisr-hackathon-2026)): open-source evidence platform for financial inclusion and poverty reduction in Rwanda, built for the NISR 2026 Big Data Hackathon. It combines 67 indicators from 14 NISR and partner publications for all 30 districts and 416 sectors, with district maps, rule-based policy priorities, an intervention planner, an explainable vulnerability model, a data-grounded assistant and a JSON API. Every figure cites its source table, and scripts rebuild the data from published files. Independent, not an official NISR product.
- **[Remote Teams Co](https://remote-teams-co.netlify.app)**: multi-tenant team-management platform with Kanban boards, 4-tier RBAC, JWT authentication, a trilingual UI (EN, FR, RW) and 70+ automated tests. Django, DRF, React, PostgreSQL, Docker.
- **ITEC Parking**: parking management app on a live production API, with lot selection, activity history and PDF receipts. OTP authentication, OAuth sign-in (Google, Facebook, Apple) and an API secret audit with rotation. Flutter, Dart.
- **G.S. Murama SMS**: school management system with 90+ tables, 150+ foreign keys, role-based dashboards for nine user roles and channel-based messaging. MySQL, Node.js, Express.
- **Unity Platform**: fintech platform connecting diaspora investors with Rwandan MSMEs, designed around the national payment-services regulatory framework, with KYC-aware flows and encrypted transactions.
- **ACT and EACC websites**: institutional sites for Africa College of Theology and East African Christian College, with faculty directories, student council pages and mega-menu navigation. PHP, JavaScript, MySQL.
